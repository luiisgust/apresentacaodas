    Como demonstrar o DAS em aula
    1. Selecione 01 · Registrar e adicione uma atividade. Hipótese inicial: uma lista será suficiente.
    2. Apresente o feedback hipotético: “Não vejo o que vence primeiro”. Selecione 02 · Organizar e adicione tarefas com datas diferentes. A lista passa a ordenar os prazos.
    3. Apresente o segundo feedback hipotético: “Quero ver só as pendentes de Matemática”. Selecione 03 · Filtrar e combine os filtros.
    4. Marque uma atividade como concluída. Recarregue a página para mostrar a persistência.
    5. Explique: o aprendizado muda a prioridade da próxima entrega. Os ciclos de uma semana são uma escolha didática, não uma regra do DAS.

    As versões compartilham os mesmos dados. Trocar de ciclo apenas muda os recursos disponíveis. Os feedbacks são simulados; não houve pesquisa real com alunos. Testes propostos com usuários e resultados esperados não devem ser apresentados como resultados medidos.
